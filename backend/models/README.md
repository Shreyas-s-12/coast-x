# Backend Models Directory

Model files (e.g. `coastx_best.pt`) are stored in the project-level `models/` directory:
`C:\CoastX\models\coastx_best.pt`

Pretrained model weights (e.g. `yolo11n.pt`) are stored in `C:\CoastX\weights\yolo11n.pt`.

Detection, tracking, zone manager, and risk engine logic are implemented in `backend/services/detection.py`.
